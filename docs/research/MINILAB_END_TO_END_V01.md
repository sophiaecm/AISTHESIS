## Purpose

Mini-Lab End-to-End v0.1 validates that the currently implemented
scientific-document components can operate as one integrated pipeline
without violating their epistemic boundaries.

The tested pipeline is:

ScientificDocumentState
→ ScientificStructureBuilder
→ ScientificStructureState
→ ScientificRelationshipBuilder
→ ScientificRelationshipGraph
→ ScientificEvidenceBridge
→ EvidenceBundle
→ CommonEvidenceState

This milestone validates engineering integration.

It does not establish scientific-document understanding accuracy.

## Epistemic Preservation

The end-to-end tests explicitly verify that epistemic categories
survive the complete pipeline.

### Result

A detected scientific result becomes:

reported_result

It does NOT become:

observed

Therefore:

reported result != observed fact

---

### Claim

A detected scientific claim becomes:

author_claim

Therefore:

author claim != established fact

---

### Hypothesis

A detected hypothesis remains epistemically:

unknown

Its presence in a scientific document does not automatically provide
support for it.

Therefore:

hypothesis candidate != supported hypothesis

---

### Relationship

A relationship generated by AISTHESIS becomes:

aisthesis_inference

It does not become verified scientific evidence.

Therefore:

relationship candidate != verified scientific relationship

---

## SUPPORTS Boundary

A Scientific Relationship Graph edge such as:

Result
→ SUPPORTS
→ Hypothesis

does not automatically populate:

EvidenceItem.supports

or:

EvidenceItem.supporting_evidence_ids

The relationship remains an AISTHESIS inference.

Therefore:

SUPPORTS graph vocabulary != demonstrated scientific support

---

## CONTRADICTS Boundary

Likewise, CONTRADICTS graph vocabulary does not automatically populate:

EvidenceItem.contradicts

or:

EvidenceItem.opposing_evidence_ids

Therefore:

CONTRADICTS graph vocabulary != demonstrated scientific contradiction

## Confidence Boundary

The end-to-end pipeline does not manufacture truth confidence.

Documentary EvidenceItem confidence remains:

None

where no justified evidence-level confidence exists.

Upstream heuristic or extraction information must not silently become
scientific truth probability.

Canonical distinction:

extractor confidence != scientific truth probability

relationship confidence != scientific truth probability

agreement != truth probability

## Coordinate-Frame Boundary

Scientific documentary evidence is not physical frame-bound evidence.

The end-to-end pipeline therefore does not fabricate:

- camera coordinates

- physical sensor frames
- metric geometry

coordinate frame.

## Known v0.1 Limitation — Lexical Rule Ordering

Scientific Structure Model v0.1 uses conservative lexical rules with
first-match classification behavior.

This creates a known rule-order interaction.

For example, a sentence describing a limitation may also contain a
lexical token associated with another structure type.

A sentence such as a limitation statement containing the word
"dataset" can be classified by an earlier dataset rule before the
limitation rule is reached.

The end-to-end testing process exposed this behavior.

The controlled fixture was made unambiguous so that the end-to-end test
validates the frozen v0.1 contract rather than silently changing the
Scientific Structure Model.

This behavior remains a documented limitation.

It must later be measured using real-paper, manually annotated
ground-truth evaluation.

It must not be interpreted as solved by the passing controlled test.
